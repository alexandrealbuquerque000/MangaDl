# 📚 Manga Downloader

A modern desktop application built with **Python** and **CustomTkinter**, designed to download, optimize, process, and convert manga chapters into high-quality digital formats (**EPUB, PDF, and CBZ**), with a special focus on e-readers like the **Amazon Kindle**.

---

## ✨ Key Features

* **Modern GUI:** Built with CustomTkinter featuring a sleek dark mode, pre-configured device profiles (such as *Kindle Paperwhite 11*), and real-time progress bars.
* **Smart Web Scraping:** Supports multiple manga sites through JSON configuration rules, with automatic detection of image containers and chapter titles.
* **Advanced Image Processing:**
  * **Smart Auto-Crop:** Automatically removes white or gray borders (scan artifacts) around pages.
  * **Full Screen Fill:** Resizes and forces images to utilize 100% of the screen, completely eliminating unwanted margins.
  * **Double Page Management:** Automatically splits double-page spreads or rotates them.
  * **Visual Filters:** Options for black-and-white conversion and dynamic contrast adjustment.
* **Volume & Cover Manager:** Group individual chapters into custom volumes and assign custom cover images.
* **Native Kindle Compatibility:** Generates EPUB files configured with fixed-layout comic metadata (*pre-paginated*), supporting right-to-left reading and automatic orientation.

---

1. Go to the **Releases** tab on the right side of this GitHub repository.
2. Download the latest compiled executable file available.
3. Run the application directly on your computer!
